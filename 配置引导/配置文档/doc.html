API 配置文档

详细的 API 服务商注册与配置教程

魔塔社区 ModelScope

推荐

阿里云旗下模型平台，免费额度充足，国内访问稳定

1

访问 https://www.modelscope.cn/ 并注册账号

2

登录后，绑定阿里云账号并进行实名认证，点击右上角头像 → 绑定阿里云账号

3

点击右上角头像 → 账号设置 → 访问令牌

4

创建或复制你的访问令牌（以 ms- 开头）

建议：创建访问令牌——有效期选择"长期使用"
5

将访问令牌填入 .env 文件的 AI_API_KEY

6

在魔塔社区 https://www.modelscope.cn/models 选择支持的文本生成模型

配置示例

# API配置 - 请填入您的实际API密钥
AI_API_KEY=ms-xxxxxxxxxxxxxxxx

# API地址
AI_API_URL=https://api-inference.modelscope.cn/v1/chat/completions

# 模型名称
AI_MODEL=ZhipuAI/GLM-4.7-Flash（可使用其他支持的文本生成模型）

DeepSeek

国产大模型，性价比高，中文理解能力强

1

访问 https://platform.deepseek.com/ 并注册账号

2

登录后，点击右上角头像 → API Keys

3

点击「创建 API Key」按钮，生成新的 API Key

建议：复制 API Key 后妥善保存，页面关闭后无法再次查看
4

在账户中心充值额度

5

将 API Key 填入 .env 文件的 AI_API_KEY

6

在 DeepSeek 平台 API 文档 查看支持的模型

配置示例

# API配置 - 请填入您的实际API密钥
AI_API_KEY=sk-xxxxxxxxxxxxxxxx

# API地址
AI_API_URL=https://api.deepseek.com/v1/chat/completions

# 模型名称
AI_MODEL=deepseek-chat
返回配置页面
