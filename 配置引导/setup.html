欢迎使用记账助手

配置 AI 功能，开启智能财务分析

记账助手的 AI 智能分析 功能需要配置您的 API 密钥。

配置信息将保存在本地的 .env 文件中，不会上传到任何服务器。

配置步骤

1

创建配置文件

在应用程序的根目录下创建一个名为 .env 的文件。

文件位置：记账助手安装目录\.env
2

编辑配置内容

将以下内容复制到 .env 文件中，并替换为您的实际配置：

.env 
# API配置 - 请填入您的实际API密钥
AI_API_KEY=your-api-key-here

# API地址
AI_API_URL=your-api-url-here

# 模型名称
AI_MODEL=your-model-name-here
3

重启应用

保存文件后，重启记账助手，AI 功能即可生效。
